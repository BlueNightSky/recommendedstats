# Commands

*Every Recommended Stats chat command.*

| Command | What it does |
|---|---|
| `/rs` | Show the current content setting |
| `/rs raid` | Show targets for Raid |
| `/rs mythicplus` | Show targets for Mythic+ (`/rs m+` works too) |
| `/rs bis` | Open or close the BiS gear window |
| `/rs talents` | Open or close the talents window |
| `/rs priorities` | Open or close the priorities window (`/rs rotation` works too) |
| `/rs link` | Copy the link to your page on the Analyzer |
| `/rs resetpos` | Put the panels back where they started |
| `/rs options` | Open the options |
| `/rs skin export` | Copy your skin as a code to share |
| `/rs skin import` | Paste someone else's skin code |
